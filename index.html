📖 User Guide

📤 Upload

  • PDF, PNG, JPG upload ya paste kar sakte ho.
  • Split PDF Pages checked ho to PDF pages alag cards bante hain.
  • Unchecked ho to ek PDF ka ek card dikhega, merge me poora PDF jayega.

🖱️ Select

  • Normal click se file select / unselect hoti hai.
  • Shift + Click se range select hoti hai.
  • Arrow Keys se focus move, Shift + Arrow se range select.
  • Ctrl + A select all, Delete selected remove.

👁️ Preview & Menu

  • Double-click se preview open hota hai.
  • Right-click card menu se PDF / PNG / JPG download, move, preview, remove.
  • Merge to PDF par right-click se custom filename popup aata hai.

⚙️ Settings

  • Explorer Selection, right-click menu, direct downloads disable / enable kar sakte ho.
  • Image PDF exact size ya A4 mode choose kar sakte ho.
  • JPG quality aur download gap adjust kar sakte ho.
  • Theme: Light, Dark, ya Device mode select karo.

📱 Mobile Tips

  • Long-press drag handle se cards reorder karo (smooth drag).
  • Swipe left / right se preview me navigate karo.
  • Pinch-zoom nahi hoga — smooth scrolling enabled hai.
