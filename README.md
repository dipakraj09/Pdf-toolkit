# PDF Studio

Static browser app for PDFs, images and DOCX previews.

## Publish on GitHub Pages

1. Upload every file in this folder to a GitHub repository.
2. In the repository, open **Settings → Pages**.
3. Choose **Deploy from a branch**, select the branch and **/(root)** folder, then save.
4. Open the Pages URL after GitHub finishes publishing.

The app uses CDN-hosted browser libraries, so it needs an internet connection when opening the site.
